# 🎂 Happy Birthday Web

เว็บอวยพรวันเกิดแบบ **เปิดของขวัญทีละฉาก** ธีมพาสเทลชมพู–ฟ้า–ครีม + ดาวระยิบ
ไม่ต้องติดตั้งอะไรเลย เปิด `index.html` ได้ทันที

---

## 🎬 ฉากทั้งหมด (4 ฉาก)

| ฉาก | ชื่อ | ลูกเล่น |
|---|---|---|
| 1 | กล่องของขวัญ | แตะกล่อง → ฝาเด้งเปิด + confetti + เพลงเริ่มเล่น |
| 2 | คำอวยพร | ข้อความพิมพ์ทีละตัว มีรูปโพลารอยด์กับลูกโป่งตกแต่งรอบ ๆ |
| 3 | รูปกระจายทั้งหน้า | รูปทั้งหมดวางเอียง ๆ แบบติดเทป ทยอยโผล่ทีละใบ — แตะรูปไหนก็ขยายดูได้ (มีปุ่มเลื่อนซ้าย-ขวา) |
| 4 | เค้ก + เทียน **(ฉากจบ)** | ทั้งจอมืด สว่างแค่บริเวณเทียน → **ลากนิ้ว/เมาส์ผ่านเปลวไฟเพื่อเป่า** → เป่าครบแล้วจอสว่างจ้า + พลุ + รูปลอยผ่านด้านหลัง |

## ✏️ วิธีแก้เนื้อหา

แก้ที่ **[js/config.js](js/config.js)** ไฟล์เดียวจบ — ชื่อ, คำอวยพร, รูป, จำนวนเทียน, ข้อความปิดท้าย, เพลง

### ใส่รูปจริง
1. ก๊อปไฟล์รูปไปไว้ใน `assets/photos/`
2. แก้ในส่วน `photos` ของ config:
```js
photos: [
  { src: 'assets/photos/1.jpg', caption: 'วันที่เจอกันครั้งแรก' },
  { src: 'assets/photos/2.jpg', caption: 'ทริปที่สนุกที่สุด' },
],
```
> - รูปแนวตั้ง (3:4) จะสวยที่สุด
> - แนะนำ **6–10 ใบ** กำลังพอดี ไม่รกจอ
> - รูป 2 ใบแรกจะถูกหยิบไปตกแต่งมุมในฉากที่ 2 ให้ด้วยอัตโนมัติ

### ใส่เพลง
1. ก๊อปไฟล์ `.mp3` ไปไว้ใน `assets/music/` ตั้งชื่อว่า `song.mp3`
2. หรือใช้ชื่ออื่นก็ได้ แล้วแก้ `music.src` ใน config ให้ตรงกัน

> ถ้ายังไม่มีไฟล์เพลง เว็บจะ**เล่นเมโลดี้กล่องดนตรีที่สังเคราะห์เอง**ให้อัตโนมัติ ไม่พัง
> เพลงจะเริ่มตอนแตะกล่องของขวัญ (เบราว์เซอร์ไม่ให้เล่นเองก่อนผู้ใช้แตะ)

### เปลี่ยนจำนวนเทียน
```js
cake: { candles: 5 }   // แนะนำ 3–9 เล่ม
```

## 🎨 เปลี่ยนสีธีม

แก้ตัวแปรบนสุดของ [css/style.css](css/style.css):

```css
:root{
  --cream:  #FFF1E2;   /* พื้นหลังครีม */
  --pink:   #FF8FC0;   /* ชมพูหลัก */
  --blue:   #7FC9FF;   /* ฟ้าพาสเทล */
  --gold:   #FFC85C;   /* ดาว/เปลวเทียน */
  --ink:    #55354E;   /* สีตัวอักษร */
}
```
อยากให้พื้นหลังเข้ม/จางกว่านี้ → ปรับ `opacity` ของ `.blob` และสีใน `.bg-layer`

## ▶️ วิธีเปิดดู

- **ง่ายสุด:** ดับเบิลคลิก `index.html`
- **แนะนำ** (ให้เพลงกับรูปโหลดถูกต้อง) รันเซิร์ฟเวอร์เล็ก ๆ:
  ```bash
  npx serve .
  # หรือ
  python -m http.server 8000
  ```
  แล้วเปิด http://localhost:8000

## 🚀 Deploy (ไว้ทีหลัง)

เป็นเว็บ static ล้วน — ขึ้น **GitHub Pages** ได้เลย:

```bash
git init
git add .
git commit -m "birthday site"
git branch -M main
git remote add origin <URL-repo-ของคุณ>
git push -u origin main
```
แล้วไปที่ repo → **Settings → Pages → Source: Deploy from a branch → main / (root)**
